# 📱 Motor de Indicações Vivo

Sistema de recomendação baseado em eventos desenvolvido com Spring Boot.

## 🎯 Objetivo

Identificar oportunidades de negócio a partir de eventos gerados pelos clientes e recomendar produtos com maior potencial de conversão.

## 🚀 Funcionalidades

- API REST com Spring Boot
- Dashboard Web
- Score de oportunidade
- Recomendação de produtos
- Justificativa da recomendação

## 📊 Exemplo

Evento:

FATURA_PAGA

Produto Recomendado:

CONTA DIGITAL

Score:

92/100
